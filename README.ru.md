## Проблема и решение

Вы хотите поручить Claude Fable, GPT-6 Luna, Gemini 3 или DeepSeek R1 рефакторинг подсистемы в вашем проекте. Вы запускаете самописный скрипт для сборки файлов, вставляете результат в промпт и сталкиваетесь с тремя проблемами:

1. **Засорение контекстного окна**: 40 000+ токенов сгорают на `Cargo.lock`, `package-lock.json`, минифицированных бандлах, SVG-иконках и бинарных артефактах.
2. **Медленные утилиты**: Существующие упаковщики на Node.js и Python работают по 2–5 секунд, потребляют ~200 МБ оперативной памяти и не дают удобного способа выбрать нужные файлы на лету.
3. **Отсутствие интерактивного контроля**: Приходится либо упаковывать весь репозиторий целиком, либо тратить десять минут на подбор флагов `--exclude`.

**repOx** решает эту задачу. Он сканирует репозитории из тысяч файлов за миллисекунды, автоматически отсекает мусор с помощью эвристик Git, предоставляет интерактивный терминальный интерфейс в стиле `lazygit` с подсветкой синтаксиса для мгновенного отбора файлов и копирует чистый, оптимизированный под конкретную модель промпт прямо в буфер обмена.

## Установка

### Через Cargo (Рекомендуется)

```bash
cargo install repox-cli
```

### Установка одной командой (macOS и Linux)

```bash
curl -fsSL https://raw.githubusercontent.com/WVDYC/repOx/main/install.sh | sh
```

### Homebrew (macOS и Linux)

```bash
brew tap WVDYC/tap https://github.com/WVDYC/repOx
brew install repox
```

### Сборка из исходников (Cargo)

Требуется Rust 1.85+ (редакция 2024):

```bash
cargo install --git https://github.com/WVDYC/repOx.git
```

Либо локальная сборка:

```bash
git clone https://github.com/WVDYC/repOx.git
cd repOx
cargo build --release
# Исполняемый файл: ./target/release/repox
```

### Автодополнение для командных оболочек (Shell Completions)

`repOx` генерирует нативные скрипты автодополнения для всех популярных оболочек:

```bash
# Zsh
repox --completions zsh > ~/.zsh/completion/_repox

# Bash
repox --completions bash > ~/.local/share/bash-completion/completions/repox

# Fish
repox --completions fish > ~/.config/fish/completions/repox.fish
```

## Интерактивный TUI (`lazygit` для промптов)

Запустите терминальный интерфейс командой `repox -i` или `repox --tui`. Интерфейс работает без аллокаций в цикле отрисовки, поддерживает лексическую подсветку синтаксиса в панели предпросмотра и копирование через системный буфер обмена или протокол OSC 52 для удалённых сессий SSH и `tmux`.

```text

│ ▾ [x] src/                                ││ 2 │ use color_eyre::eyre::Result;     │
│   [x] cli.rs                     7.1 KB   ││ 3 │                                   │
│   [x] main.rs                    3.8 KB   ││ 4 │ fn main() -> Result<()> {         │
│   [x] Cargo.toml                 1.4 KB   ││ 5 │     // fast parallel walk...      │
└───────────────────────────────────────────┘└───────────────────────────────────────┘
  [Claude Fable 5.1 (1M)] 26/26 files | 45,260 / 1,000,000 tokens (4.5%) [■░░░░░░░░░] 166.0 KB
  [↑/↓] Move  [Space] Toggle  [/] Search  [a] Invert  [c] Copy  [C] CLI Cmd  [Enter] Dump  [q] Quit
```

### Горячие клавиши

| Клавиша | Действие |
| :--- | :--- |
| `↑` / `k` или `↓` / `j` | Перемещение курсора вверх / вниз |
| `←` / `h` или `→` / `l` | Свернуть / развернуть директорию |
| `Space` | Включить или исключить файл/папку (каскадные чекбоксы с 3 состояниями: `[ ]`, `[-]`, `[x]`) |
| `a` | Выбрать всё / инвертировать выделение |
| `/` | Открыть живой нечёткий поиск (`nucleo-matcher`) |
| `Esc` | Очистить поисковый запрос / сбросить фильтр |
| `c` | **Скопировать в буфер обмена**: упаковать выбранные файлы (системный буфер или OSC 52 по SSH/tmux) и выйти |
| `C` (`Shift+C`) | **Скопировать воспроизводимую CLI-команду**: скопировать точную команду `repox -I file1 -I file2` в буфер обмена и выйти |
| `Enter` | На файле: вывести контекст в stdout/файл и выйти; на папке: свернуть/развернуть |
| `q` | Выйти без выполнения действий |

## Быстрый старт и основные сценарии работы

### 1. Интерактивный отбор файлов с контролем бюджета токенов
```bash
repox -i -p fable
# Поддерживаются профили: -p luna, -p gemini, -p deepseek, -p o1, -p claude, -p llama
```
Запускает TUI, откалиброванный под размер контекстного окна целевой модели (например, 1 000 000 токенов для Fable/Gemini, 1.05M для Luna).

### 2. Копирование всего репозитория в буфер обмена (без TUI)
```bash
repox -c
```
Копирует XML-промпт в формате Claude напрямую в системный буфер обмена (при работе через удалённый SSH или `tmux` автоматически используется фоллбэк на escape-последовательности OSC 52):
```text
✓ Copied to clipboard: 42 files (142.6 KB) in 4.12ms
```

### 3. Точный офлайн-подсчёт токенов
```bash
repox -c -t -p claude
```
```text
✓ Copied to clipboard: 42 files (142.6 KB, 38,120 tokens) in 38.50ms
```

### 4. Сохранение промпта в формате Markdown в файл
```bash
repox -f md -o context.md
```

### 5. Фильтрация по подпапке, максимальному размеру файла и глубине вложенности
```bash
repox src/ -s 500KB -d 3 -o prompt.xml
```

### 6. Передача чистого промпта через пайп в другую утилиту
```bash
repox -q | pbcopy
```

### 7. Архитектурный срез / только сигнатуры (`--outline` / `--signatures-only`)
```bash
repox --outline -c
```
Извлекает определения типов, структуры (`struct`), трейты (`trait`), интерфейсы, классы и сигнатуры функций для **Rust, Python, Go, TypeScript/JavaScript, C/C++ и Java**, сворачивая тела реализаций в `{ /* ... */ }`. Сжимает кодовые базы из десятков тысяч строк на 60–90% по токенам, что идеально подходит для проектирования архитектуры и навигации LLM по крупным проектам.

### 8. Синтетический вывод Tool-Call (`-f tool-call` / `-f json`)
```bash
repox -f tool-call -c
```
Форматирует файлы в виде JSON-массива ответов инструмента `read_file`. Идеально подходит для агентных фреймворков (Ollama, OpenAI, Anthropic message loops), где модели воспринимают результаты вызова инструментов как достоверный источник истины, а не как вставленный пользователем текст.

### 9. Умная сводка lock-файлов и воркфлоу ComfyUI (`--summary-locks`)
```bash
repox --summary-locks -c
```
Вместо полного игнорирования огромных lock-файлов (`Cargo.lock`, `package-lock.json`, `pnpm-lock.yaml`, `poetry.lock`, `yarn.lock`, `go.sum`) или сжигания 40 000+ токенов на сырые графы зависимостей и JSON-файлы визуальных воркфлоу ComfyUI, флаг `--summary-locks` преобразует lock-файлы в компактный манифест `пакет @ версия` (`.deps.txt`), а графы ComfyUI на 30 000 токенов сжимает в отсортированные манифесты нод и промптов (экономия 85–95% токенов).

### 10. Упаковка с учётом изменений Git (`-m, --modified` и `--staged`)
```bash
# Упаковать только изменённые и неотслеживаемые файлы рабочего дерева для точечной отладки
repox -m -c

# Упаковать только индексированные (staged) файлы вместе с unified git diff для код-ревью или описания PR
repox --staged -c
```
Опрашивает статус Git и `git diff`, упаковывая только затронутые файлы вместе с патчем изменений (`unified diff`). Это даёт языковой модели как точные построчные изменения, так и полный контекст окружающего кода для ревью пулл-реквестов и исправления багов.

### 11. Автоматический укладчик в бюджет токенов (`-b, --budget` / `--max-tokens`)
```bash
repox --budget 50k -c
# Поддерживаются точные числа или сокращения: 32k, 64k, 100k, 1m
```
Гарантированно укладывает любой репозиторий строго в заданный лимит токенов. `repOx` отдаёт наивысший приоритет ключевым точкам входа (`main.rs`, `lib.rs`, `index.ts`) и изменённым в Git файлам, последовательно сжимает крупные второстепенные модули до архитектурных сигнатур (`outline`), и лишь в крайнем случае отбрасывает тестовые данные и фикстуры с самым низким приоритетом.

### 12. Потоковая маскировка секретов (`-r, --redact-secrets`)
```bash
repox -r -c
```
Запускает однопроходный лексический сканер по всем упаковываемым файлам, автоматически обнаруживая и заменяя захардкоженные ключи и токены — включая ключи OpenAI (`sk-...`, `sk-proj-...`), Anthropic (`sk-ant-...`), токены GitHub (`ghp_...`, `gho_...`, `github_pat_...`), идентификаторы ключей AWS (`AKIA...`), а также блоки приватных ключей PEM/OpenSSH `-----BEGIN ... PRIVATE KEY-----` — на безопасную заглушку `[REDACTED_SECRET]`.

### 13. Компилятор промптов и консистентности для AI-видео (`--video-prompt`)
```bash
repox --video-prompt "Please generate a video of a cyberpunk courier in a yellow trench coat on 35mm anamorphic lens in neon rain. Then she leaps across a rooftop as a drone tracks her." -c
```
Компилирует описания сцен на естественном языке в структурированные мульти-шот промпты с максимальной концентрацией внимания для **Grok Video, Kling, Sora, Veo и Wan 2.1**. Удаляет разговорный шум, синтезирует блок фиксации персонажа `<character_lock>` (`subject`, `lens`, `lighting`) и разбивает сцену на 5-секундные блоки `<shot>` с явными директивами `[Camera]`, `[Motion]` и `[Continuity: anchor=sharpest_tail_frame]`, опирающимися на сверхбыстрый (<1 мс) алгоритм оценки резкости кадра через дисперсию лапласиана 3x3.

```

Использует защищённые от коллизий блоки кода (автоматически экранирует вложенные обратные кавычки):

└── src
    └── main.rs
```

# Repository Files

```toml

```

```
````

## Архитектура и внутреннее устройство

В основе `repOx` лежат три инженерных принципа: **рендеринг без аллокаций**, **детерминированный вывод** и **безотказная эргономика терминала**.

### 1. Непрерывная арена `FlatTree` (`crates/repox-tui/src/tree.rs`)
Классические рекурсивные деревья виджетов постоянно выделяют память на каждом кадре и страдают от промахов кэша процессора. `repOx` разворачивает иерархию файлов в единый непрерывный вектор `Vec<Node>` в порядке прямого обхода (pre-order):
- Поддеревья занимают непрерывные срезы `[start..end]`.
- Сворачивание и разворачивание папок выполняется за $O(1)$ через маску среза.
- Переключение чекбоксов пересчитывает агрегаты папок за один обратный проход по срезу без единой аллокации памяти в цикле отрисовки.

### 2. Многопоточный обход с перехватом задач (`crates/repox-core/src/scanner.rs`)
- Использует `ignore::WalkBuilder` с неблокирующей пакетной передачей через каналы.
- Автоматически учитывает правила `.gitignore`, `.ignore` и `.repoxignore`.
- Определяет бинарные файлы по 8-килобайтной NUL-байт эвристике Git и отсекает lock-файлы (если не включён `--summary-locks`), минифицированные бандлы, SVG и приватные ключи (`.env*`, `*pem`, `*id_rsa*`) ещё до чтения содержимого файла в память.

### 3. Отрисовка TUI в `stderr` для чистоты UNIX-пайпов
Интерактивный интерфейс рендерится исключительно в поток `stderr`. Благодаря этому поток `stdout` никогда не загрязняется управляющими ANSI-кодами, что позволяет строить чистые конвейеры:
```bash
repox -i | llm prompt "объясни архитектуру проекта"
```

### 4. Безопасность терминала и буфер обмена через OSC 52
Использует RAII-обёртку `TerminalGuard` с перехватчиком паник (`panic hook`), гарантируя отключение raw-режима и выход из альтернативного экрана даже при аварийном завершении. Операции с буфером обмена используют `arboard` с автоматическим переключением на управляющие последовательности ANSI OSC 52 для бесшовного копирования внутри headless-сессий SSH и `tmux`.

## Справочник аргументов CLI

```text
repox [OPTIONS] [PATH]

Аргументы:
  [PATH]                     Целевая директория репозитория [по умолчанию: .]

Опции:
  -i, --interactive          Запустить интерактивный TUI-выбор файлов (алиас: --tui)
  -f, --format <FORMAT>      Формат вывода: 'xml' (Claude), 'markdown' / 'md' или 'tool-call' / 'json' [по умолчанию: xml]
  -c, --copy                 Скопировать итоговый контекст напрямую в буфер обмена (поддерживает OSC 52)
  -o, --output <FILE>        Записать отформатированный контекст в файл вместо stdout
  -t, --tokens               Подсчитать общее количество токенов многопоточным токенизатором tiktoken
  -p, --token-profile <PROF> Профиль токенизатора: 'fable' (Claude Fable 5.1, 1M), 'luna' (GPT-6 Luna, 1.05M), 'claude', 'o1', 'deepseek', 'gemini', 'llama', 'cl100k' [по умолчанию: cl100k]
  -b, --budget <TOKENS>      Автоматически уложить репозиторий в строгий лимит токенов (напр. 50k, 100000; алиас: --max-tokens)
  -r, --redact-secrets       Сканировать и маскировать API-ключи, токены и приватные ключи заглушкой [REDACTED_SECRET]
      --video-prompt <TEXT>  Скомпилировать описание видео в мульти-шот промпт с <character_lock> и 5-секундными блоками <shot>
      --outline              Извлекать только архитектурные сигнатуры и определения типов (алиас: --signatures-only)
      --summary-locks        Сжимать lock-файлы и JSON-воркфлоу ComfyUI в компактные манифесты
  -m, --modified             Упаковать только изменённые и неотслеживаемые файлы Git вместе с unified diff
      --staged               Упаковать только индексированные (staged) файлы Git с unified diff для PR и ревью
  -s, --max-file-size <SIZE> Пропускать файлы, превышающие порог размера (напр. 500KB, 1.5MB) [по умолчанию: 1MB]
  -d, --max-depth <DEPTH>    Максимальная глубина вложенности директорий при обходе
      --no-gitignore         Не учитывать правила из файлов .gitignore
      --no-repoxignore       Не учитывать правила из файлов .repoxignore
      --include-hidden       Включать скрытые файлы и директории
  -e, --exclude <GLOB>       Glob-шаблон для исключения файлов (можно указывать несколько раз)
  -I, --include <GLOB>       Glob-шаблон для принудительного включения (можно указывать несколько раз)
  -j, --threads <N>          Количество рабочих потоков (по умолчанию равно числу логических ядер CPU)
      --completions <SHELL>  Сгенерировать скрипт автодополнения (bash, zsh, fish, powershell, elvish)
  -q, --quiet                Отключить вывод информационных сводок в stderr
  -v, --verbose              Включить подробное логирование для отладки
  -h, --help                 Показать справку
  -V, --version              Показать версию
```
